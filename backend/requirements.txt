# These are the exact versions of the environment in which `pytest tests -q`
# is green (308 passed) on **python 3.14** (Homebrew, /opt/homebrew/bin/python3).
# Pin first, upgrade later: nothing here was bumped to "fix" anything.
#
# ── langgraph version skew (measured, not guessed) ───────────────────────────
#   python3.14 → langgraph 0.2.76   ← the reference environment, use this
#   python3.13 → langgraph 0.6.4
# The two differ in what `graph.ainvoke()` returns when a gate interrupts:
# 0.6.x puts the `Interrupt` list under the `__interrupt__` key of the result
# dict, 0.2.x does not (the interrupt is only readable from
# `graph.get_state(config).tasks[*].interrupts`). `tests/test_graph_structure.py`
# (`_interrupt_of`, added in 75d90ee) accepts both. `graph.astream(...,
# stream_mode="updates")` — what app/main.py actually uses — *does* emit an
# `{"__interrupt__": [...]}` update on both versions, so the server path is
# unaffected; only ainvoke-based tests were.
#
# Run the backend and the tests with python3.14:
#   PYTHONPATH=$(pwd) python3 -m pytest tests -q
#   PYTHONPATH=$(pwd) python3 -m uvicorn app.main:app --port 8021
# The Cloud Run image (Dockerfile) is python 3.12 and installs this same file,
# so the pins are what runs in production too.
